# Xbox-save-archive

Original Xbox Back up saves



This is a collection of most saves posted online based on XBXBX PPN Archive and gamefaq. Only collected 1 for each game do how they where archived as well as few roaster updates. Still missing saves from The Tech Game which add at a later date. 



Note max save limit is 240.

## EEPROM locked saves

A small number of games lock the save file to a particular console. You can see [the list of non-roamable games here](https://consolemods.org/wiki/Xbox:Games_with_Non-Roamable_(EEPROM-Locked)_Saves) along with some information on re-signing them for your Xbox.
